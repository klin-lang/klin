## Why separate

Same split as [`klin_st7735`](https://github.com/klin-lang/klin_st7735) vs board packs: the panel command stream and framebuffer packing do not own SPI/GPIO. Apps or board packs supply `Wire`.

Default geometry: **Waveshare ESP32-S3-RLCD-4.2** landscape **400×300** → caller FB **15000** bytes.

## Scope (`@v0.2.0`)

- Everything from `@v0.1.0` (Wire / attach / clear / fill / pixel / rect / flush)
- `hline` / `vline` / `draw_rect` on caller `[]u8`
- 5×7 font: `font5x7_col` / `font_char_w` / `font_char_h`
- `draw_char` / `draw_text` / `draw_text_n` (ASCII as `[]i32`)
- `color_black` / `color_white` (`0` / `1`)
- Host `klin test` + `examples/host_smoke.kl`

### Later (not this tag)

- Alternate tabs / rotations beyond Waveshare landscape defaults
- Generic `klin_st7789` extract from Pico-LCD-1.14
- Larger fonts / proportional text

## Out of scope

- ESP-IDF / `machine_esp` inside this package
- Battery ADC / board pin map ([163](163-board-waveshare-esp32-s3-rlcd-42.md))
- Hidden framebuffer allocation

## Contract (prime rule)

- No Klin GC / hidden heap — framebuffer is caller `[]u8`.
- White = bit **1**; black = bit **0**.
- SPI Mode 0; baud and CS/DC/RST are caller-owned.

## Usage

```sh
klin get github/klin-lang/klin_st7305@v0.2.0
klin test klin_st7305
```
